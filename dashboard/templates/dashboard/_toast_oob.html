{% comment %} htmx's position-based OOB swap ("beforeend:#selector") inserts the CONTENT of the hx-swap-oob-marked element into the selector-matched target — the marked element's own tag/attributes are just a carrier, never inserted themselves (this mirrors htmx's own canonical "append to a list" example, which id-matches an element to itself for the same reason). So the OOB marker has to sit on a `#toast-container` stand-in, with the real `.toast` element nested inside it as the content that actually lands in the page. {% endcomment %}
